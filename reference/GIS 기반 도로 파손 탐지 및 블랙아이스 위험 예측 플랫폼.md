# GIS 기반 도로 파손 탐지 및 블랙아이스 위험 예측 플랫폼

## 1. 프로젝트 개요

### 프로젝트명

GIS 기반 AI 도로 파손 탐지 및 블랙아이스 위험 예측 플랫폼

### 프로젝트 목표

도로 영상을 활용하여 포트홀(Pothole) 및 균열(Crack)을 자동 탐지하고,

기상 데이터 기반 블랙아이스 위험도를 예측하여 GIS 지도 상에서 시각화하는 통합 플랫폼 구축

---

## 2. 최종 시스템 구성

```text

↓
AI 탐지 모델 (YOLO)

포트홀
균열
↓

↓
PostGIS 저장
↓
QGIS 시각화

────────────────────────

ASOS/AWS 기상데이터
↓
전처리
↓
블랙아이스 위험도 예측 모델
↓
PostGIS 저장
↓
QGIS 시각화

────────────────────────

Spring Boot API
↓
통합 대시보드
```
